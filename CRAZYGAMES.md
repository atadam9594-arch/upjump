# CrazyGames R13 candidate

Build: npm test && node scripts/build-crazygames.mjs. Cloudflare Pages also builds public/downloads/upjump-crazygames.zip from the same commit. ZIP includes index.html at the root and all local runtime assets; excludes prior downloads and server headers. The SDK v3 script is only injected for the portal package. Data module is initialized before game launch and uses SDK storage on portal; standalone uses localStorage. Select the Data Module progress-save option in the developer portal. SDK audio mute takes precedence. No rewarded or midgame ads yet. Required portal preview videos (landscape and portrait) and actual device/SDK QA remain external steps. Cover sizes: 1920x1080, 800x1200, 800x800. Do not submit until browser and SDK preview tests pass.
